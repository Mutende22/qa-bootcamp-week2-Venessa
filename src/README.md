## Profile Validation
The `profile-validation.ts` file contains a user profile validation exercise. It uses TypeScript types and optional chaining to safely check notification settings.

The `isNotified()` function returns:
- `true` when notifications are enabled.
- `false` when settings are missing.
- `false` when the notifications property is missing or disabled.
